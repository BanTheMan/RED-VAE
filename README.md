# RE-LDM

The RE-LDM, a Reasoner-Executor Latent Diffusion architecture that maps electroencephalography (EEG) signals to stable diffusion image generation by learning an internal representational “language” unconstrained by syntax or semantics of natural language. The model isolates reasoning and execution into two distinct components: a trainable EEG Vision Transformer that infers latent structures into semantics, and a pretrained latent diffusion model that executes image generation.
